# Stage 6: SCHEDULE

**Model:** the run itself (Sonnet). No subagents.

Only when `STATE.md` records the founder's approval for this exact piece, in the founder's own words, with a date.

**Read:** `episodes/<id>/post.md` and the founder's approval in `STATE.md`.

**Do:**
1. Host the approved files where the scheduler can reach them, as the run instructions say.
2. Schedule each post in Metricool for @pxi.app exactly as `post.md` lists it: the platform, the cut, the
   caption, the cover, the time. Instagram first, as a trial reel when `post.md` says so. Shorts are marked as
   Shorts and not made for kids. No other account, and no edit to any post the founder made by hand.
3. Read the schedule back and check each post is there with the right file and time.
4. Add one row for each post to the ledger in `engine/learning.md` with its tags and no numbers yet.
5. Set `STATE.md` to the next item in the queue.

**Gate:** every approved post is scheduled and confirmed, and nothing else was changed. If the scheduler is not
connected or a post fails, leave it unscheduled, say exactly which, and stop.
**Report:** what is scheduled and when, in one line each.
