# Premise bank

One line each. A premise gets in only if it passes all five checks, and the checks are written next to it.
Stage 0 and stage 1 add here. Stage 1 takes the top APPROVED one. Only the founder marks a premise APPROVED.

Checks: **F** the PXI feature that runs the plot (from `bible/pxi-product.md`) · **P** the small social problem ·
**A** the easy thing Nio avoids doing · **C** what it costs him · **T** the true thing underneath.

Format:

```
- [CANDIDATE] <one sentence, mundane, no wordplay>
  F: … · P: … · A: … · C: … · T: …
```
