# The funny log (Naty's)

Anything Naty found funny: a clip, a line from a show, a meme, something that happened, a face someone made.
The writers' room reads this before every script and must use at least one entry that has not been used yet,
as a mechanism (why it is funny), never copied word for word. Mark the entry `USED BY: <episode>` after.

How it gets here: Naty writes **funny:** followed by anything, in any chat or thread. Whoever receives it
appends it below, word for word, with the date, and a one-line note on what makes it funny.
