# Episode orders (Naty orders the next episode by naming what it should have)

Naty writes **order:** followed by whatever the next episode should have: a place, a person, a situation, a
joke from the funny log, a tone, a holiday, a PXI feature, anything. One line is enough. Whoever receives it
adds it below. The next WRITE run takes the oldest open order **before** the premise bank, builds the episode
around every element named, and marks it `DONE: <episode>`.

Example: `order: rooftop party, Maya trying to set Nio up, a guy who only speaks in voice notes, ends eerie`
